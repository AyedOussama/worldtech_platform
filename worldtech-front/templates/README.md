# Modèles fournis
Ces fichiers sont des aides d'intégration, pas une application prête à démarrer.

| Élément | Lot | Statut |
|---|---|---|
| design/tokens.json et CSS | FE02 | Références proposées, contrastes de départ contrôlés |
| theme/theme-init.js | FE02 | Script isolé, syntaxe et cas de préférence contrôlés |
| config/runtime-config.example.json | FE01 | Exemple public, sans secret |
| config/runtime-config.schema.json | FE01 | Schéma à appliquer au bootstrap réel |
| deploy/nginx-spa.conf.example | FE14 | Routage à adapter ; aucun nginx -t exécuté dans la création du pack |
| api/CONTRACT_WORKSHEET.md | Chaque intégration | Fiche à remplir depuis OpenAPI réel |
| recette | Chaque lot | Données synthétiques et compte rendu |

Copier et adapter seulement les modèles utiles au lot courant. Préserver les conventions du dépôt et ne pas écraser des fichiers existants.
