# Références de thème
tokens.json décrit les valeurs proposées dans un format interne au pack ; ce n'est pas un preset PrimeNG directement importable.
worldtech.tokens.css expose les mêmes couleurs en variables CSS. FE02 les rapproche des tokens sémantiques et de composants de la version réellement installée.
La police n'est pas incluse : récupérer ses fichiers et conserver leur licence lors de l'intégration.
Les contrôles de contraste du pack portent sur ces couleurs de départ ; ils ne valident pas les états réels d'un composant.
